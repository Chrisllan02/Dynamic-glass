# Dynamic Glass

Extensão do Chrome que substitui a Nova Guia por uma interface de vidro líquido, com ilha dinâmica, fundos animados e integração opcional com o Gemini.

## Rodar localmente

```bash
npm install
npm run dev
```

## Gerar a extensão

```bash
npm run build
```

Depois, em `chrome://extensions`, ative o modo do desenvolvedor e carregue a pasta `dist`.

A chave do Gemini é informada pelo usuário nas configurações da extensão e fica só no armazenamento local do navegador.
